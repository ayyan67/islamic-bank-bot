# Islamic Bank — Privacy Policy

_Last updated: August 14, 2026_

Islamic Bank ("the bot") is a community economy and engagement bot for Discord. This policy explains what data the bot collects, why, and how it is handled.

## Data We Collect and Store

To provide its features, the bot stores the following in a private database on our own server:

- **Discord user ID and username** — to associate your economy balance, prayer streaks, trivia scores, and club membership with your account.
- **Server (guild) IDs and membership** — to scope balances, leaderboards, clubs, and server settings to each server, and to remove users from a server's leaderboards when they leave it.
- **Activity records** — economy transactions (e.g. deposits, transfers, rewards), prayer check-ins, trivia results, shop purchases, and marketplace task activity, all tied to your user ID.
- **Command usage logs** — the command name, user ID, server ID, and channel ID of commands you run, kept for debugging and abuse prevention. Logs never include message text.

## Data We Do NOT Collect

- **Message content is never stored.** The bot reads messages in servers only to detect its own text commands (e.g. `.help`, `.pray fajr`) and to check answers during active trivia games. Messages are processed in memory and immediately discarded.
- No presence/online-status data, avatars, email addresses, or other profile information.
- No data is sold, shared with third parties, or used to train AI/ML models.

## Your Choices

- You can use the bot entirely through slash commands; text commands and trivia are optional.
- Server administrators can restrict or disable the bot's commands per channel or server using the bot's built-in command policy system.
- To request deletion of your stored data, contact us (below) with your Discord user ID.

## Data Retention

Data is kept while the bot remains in a server and you remain a participant. Server data may be deleted after the bot is removed from that server.
